# 전처리 후보 검토 연습

raw.csv는 합성 주문 내역이다. candidate.csv는 누군가 제안한 전처리 후보다. 실제 시험 문제나 정답이 아니다.

업무 요청은 월별 분석에 앞서 전처리 후보의 적절성을 검토하는 것이다. 제공된 파일에는 월 정보가 없으므로 임의로 월을 만들어 집계하지 않는다. 어떤 검토까지 가능한지 범위를 정한다.

누락값과 중복, 숫자가 아닌 값, 환불 내역이 있다. 각각을 어떻게 처리해야 하는지는 정해져 있지 않다. 원본과 후보의 차이를 먼저 확인하고, 업무 담당자에게 물을 내용과 현재 확정할 수 있는 사실을 구분한다.

1. task-steering으로 필수 결과와 가정을 정리한다.
2. artifact-checking으로 원본과 후보를 검사하고 전후 영향을 확인한다. 음수라는 사실만으로 환불을 오류라고 결론내리지 않는다.
3. 실제 관찰을 바탕으로 assumptions, checks, limitations 키를 포함한 summary.json을 작성한다. 파일 형식을 맞추는 것과 결론이 타당한 것은 별개다.
4. artifacts.json은 파일과 구조만 검사한다. 데이터 처리 정책의 적절성은 사람이 판단한다.
5. explain-artifact로 자신이 한 검토를 이해한 뒤 AI와 기록을 닫고 직접 설명한다. 제거 이유, 집계 영향, AI 위임과 직접 확인의 차이를 물어볼 수 있다.

연습 데이터는 복사한 별도 작업 폴더에서 다룬다. 이 저장소에 실제 업무 데이터나 시험 결과를 추가하지 않는다.
