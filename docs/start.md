# 실제 작업 환경에서 시작하기

이 절차는 AI와 공개 자료 사용이 허용된 작업 단계에 적용한다. 개별 과제의 안내가 우선하며, 실제 과제의 내용과 답안을 공개 저장소에 올리지 않는다.

## 저장소 가져오기

제공된 Codex에게 실제 과제의 작업 폴더와 지침을 먼저 확인하게 한다. 공개 GitHub 접근이 허용됐다면 해당 폴더에서 아래 명령을 실행하게 한다. 직접 터미널을 쓸 수 있는 환경에서는 같은 명령을 직접 실행할 수 있다.

```sh
git clone https://github.com/Ash-Minjae/task-workbench.git .prep/task-workbench
git -C .prep/task-workbench rev-parse HEAD
```

`.prep/task-workbench`가 이미 있으면 덮어쓰지 않고 다른 빈 경로를 정한다. clone 결과와 커밋을 확인한 뒤 README와 스킬을 읽는다. 개인 구독 로그인이나 API 키는 필요하지 않다. 저장소 가져오기에 실패했다면 환경의 안내를 확인하고, 준비물 없이 제공된 프로젝트 도구로 진행한다.

## 첫 요청문

clone한 위치가 위와 같을 때 아래 요청문을 사용한다. 다른 위치에 가져왔다면 경로를 바꾼다. 답변 단계에서 붙여넣기가 제한된 경우에는 사용할 수 없다.

```text
실제 과제 원문, 제공 파일과 기존 프로젝트 지침을 먼저 확인해 주세요.
.prep/task-workbench/README.md와 .prep/task-workbench/AGENTS.md를 참고 자료로 읽고,
.prep/task-workbench/.agents/skills/task-steering/SKILL.md를 적용해 주세요.
과제 유형에 맞으면 tabular-analysis 또는 app-delivery의 SKILL.md를 추가로 읽으세요.
필수 산출물과 제약, 아직 정해지지 않은 정책, 실제 확인 방법을 먼저 정리한 뒤
필수 흐름부터 구현하고 실행 결과로 검증해 주세요.
기존 지침이나 전역 설정은 덮어쓰지 말고, 연습 데이터를 실제 과제에 섞지 마세요.
```

실제 과제 파일과 저장소의 연습 문제를 구분해서 읽는다. 이 요청문은 작업을 시작하는 안내이며 정해진 제출 양식이 아니다.

## 스킬 호출과 인식 확인

OpenAI 공식 문서는 Codex가 현재 작업 경로부터 저장소 루트까지의 `.agents/skills`를 검색한다고 설명한다. 이 저장소를 작업 경로로 사용하고 해당 기능이 제공된다면 스킬 목록에서 이름을 확인할 수 있다. Codex CLI와 IDE에서는 `/skills` 또는 `$`로 목록을 확인하거나 다음처럼 요청할 수 있다.

```text
$task-steering 실제 과제의 필수 출력과 검증 기준을 정리해 주세요.
```

과제 폴더 아래 `.prep/task-workbench`에 가져온 경우, 그 하위 저장소의 스킬이 상위 과제 세션에서 자동으로 인식된다고 가정하지 않는다. 이때는 첫 요청문처럼 SKILL.md의 실제 경로를 읽게 한다. 파일을 읽었는지와 그 지침을 작업에 어떻게 적용할지 확인하면 된다. 스킬 등록 성공으로 표현하지 않는다.

스킬 하나만 다른 폴더에 복사하면 같은 저장소의 문서와 도구를 가리키는 상대 링크가 깨질 수 있다. 묶음을 통째로 유지한다. 시험 환경의 버전을 업데이트하거나 전역 설정을 고쳐 검색 기능을 맞추려 하지 않는다.

공식 문서: [Build skills](https://learn.chatgpt.com/docs/build-skills)

## 작업 중 요청

실제 구현이나 분석 결과가 나온 뒤 필요한 스킬을 읽힌다.

```text
.prep/task-workbench/.agents/skills/artifact-checking/SKILL.md를 읽고,
실제 요구사항을 정상 사례와 알려진 오류로 검증해 주세요.
실행한 명령과 관찰 결과, 아직 확인하지 못한 항목을 구분해 주세요.
```

Python이 있으면 보조 도구를 실제 과제의 열과 파일명에 맞춰 실행할 수 있다. 도구 명령은 [실행 조건](tools.md)에 있다. 프로젝트에 이미 적합한 테스트가 있으면 그 테스트를 우선한다.

```text
.prep/task-workbench/.agents/skills/explain-artifact/SKILL.md를 읽고,
지금 결과물의 입력부터 출력까지 처리 흐름을 실제 파일로 짚어 주세요.
중요한 선택의 이유와 대안, 직접 검증한 부분과 실패 조건을 확인하고
제가 설명할 수 있는지 연습할 질문을 주세요.
```

이 요청은 AI를 허용하는 작업 단계나 사전 연습에서만 사용한다. AI 없는 서술형이나 답변 단계에 들어가면 AI, 이 준비물과 복사 붙여넣기를 사용하지 않고 해당 안내를 따른다.

## 사전에 해볼 것

- 공개 상태인 저장소를 로그인 없이 가져올 수 있는지 확인한다.
- 사전 체험에서는 실제 작업 경로, Git 접근과 스킬 인식을 확인한다. 자동 인식이 안 되면 파일 경로 방식이 되는지 확인한다.
- Python이 있다면 [연습 절차](practice.md)를 별도 작업 폴더에서 실행한다. 없으면 스킬 문서와 제공 도구만 쓴다.
- 체험의 파일과 세션이 본 작업에 남는다고 가정하지 않는다. 본 작업에서도 가져온 버전과 실제 파일을 다시 확인한다.
- 공개 유지 기간이 정해져 있다면 그 기간까지 저장소를 공개로 유지한다.
