# 표 데이터 분석

한 행이 무엇인지, 식별자와 측정값이 무엇인지 확인한다. 기간, 단위, 모집단과 분모를 원문에서 정한다. 월별 비교가 필요하더라도 실제 날짜 필드와 관측 기간이 없으면 만들어 내지 않는다.

원본의 행 수와 결측, 중복을 관찰한 뒤 처리 정책을 정한다. 결측은 0과 다르고 음수는 환불일 수 있다. 같은 식별자가 여러 행에 등장하는 이유를 확인하기 전에 중복 제거를 확정하지 않는다. 변환은 원본을 보존한 별도 결과에 수행한다.

조인한다면 양쪽 키의 고유성과 매칭되지 않는 행을 확인한다. 조인 전후 행 수와 합계를 대조해 다대다 결합으로 값이 불어난 경우를 잡는다. 집계는 전체뿐 아니라 결론에 중요한 집단별로 비교한다. 평균과 비율의 분모가 달라졌는지도 확인한다.

작은 표본을 별도로 계산해 핵심 수치를 대조한다. 제안한 삭제나 변환 정책이 결과를 얼마나 바꾸는지 확인하고, 그 정책이 승인되지 않았다면 가정으로 남긴다. 관측한 차이를 인과 효과로 바꾸거나 부족한 기간을 전체 추세로 확대하지 않는다.

결론마다 실제 계산 결과와 해당 입력을 연결한다. 요청이 의사결정이라면 수치가 어떤 선택을 지지하는지, 어떤 추가 정보가 결론을 바꿀 수 있는지 설명한다. 검사 도구는 [artifact-checking](../artifact-checking/SKILL.md)에서 필요한 것만 선택한다.
