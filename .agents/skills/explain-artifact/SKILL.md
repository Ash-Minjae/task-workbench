# 산출물 이해

실제 파일과 실행 결과를 확인한다. 기억이나 일반론만으로 설명하지 않는다. AI를 허용하는 작업 단계와 사전 연습에서 사용한다.

입력이 어떤 처리와 가정을 거쳐 출력으로 이어지는지 따라간다. 중요한 함수, 계산과 주장을 실제 위치에 연결한다. 선택한 방법과 버린 대안, 직접 확인한 결과와 남은 한계를 구분한다.

결과를 바꿀 수 있는 실패 조건 하나를 확인한다. 코드 과제는 오류 경로와 검증을, 데이터 과제는 처리 정책이 집계에 주는 영향을 설명한다. 사람이 표본을 대조하거나 자신의 말로 설명하도록 돕는다.

연습 질문은 실제 결과물에서 만든다. 선택 이유, AI에 맡긴 범위, 직접 검증한 부분, 실패와 수정, 한계를 물을 수 있다. 정해진 문항의 출제 내용을 예측했다고 말하지 않는다.

AI 없는 답변은 도구를 닫고 직접 타이핑한다. 작업 기록을 열람할 수 있다고 가정하지 않는다. 질문의 전제가 실제 결과와 다르면 그 차이를 밝힌다.
